What is behind the numbers

  • rtk compressed pytest and git output. On the tasks where it compressed the most, the agent re-ran commands with rtk bypass and took more turns, and each extra turn re-reads the cached context. See FINDINGS.
  • caveman: Claude Code 2.1.252 skips a small background title-generation call whenever any SessionStart hook is configured. caveman registers one, which explains its apparent saving in the pilot. The noop-hook arm reproduces that side effect; against it caveman's effect is about zero. See FINDINGS.

Limitations

  • One model (Haiku 5.5) and one Claude Code version, which does not recognize this model ID. That is the same for every arm.
  • Small-to-medium synthetic tasks. Haiku solved nearly all of them, so the comparison rests on cost, not solve rate.
  • Pinned tool versions (rtk v1.1.0, caveman v4.0.1); newer releases were not tested.
  • Costs are API-equivalent: runs used a Claude Code subscription and usage was priced at list prices.
