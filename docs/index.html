TokenTrial leaderboard

Does a token-saving tool lower what a coding agent costs per correctly solved task? Each tool is compared with baseline and with a matched control that reproduces its side effects on Claude Code without the tool itself. Write-up: v0.3 FINDINGS.

v0.3 in brief

  • No tool saved money beyond the noise floor on either model.
  • caveman v4.1.0 cost 25% more on Sonnet 5.5 (95% CI +12% to +44%) than its control. Its SessionStart hook adds about 1,850 tokens of instructions to every session, and Sonnet's output, already short, didn't get shorter. On Haiku 5.5, where output fell about 17%, it was −8% (CI −19% to +5%).
  • rtk's penalty replicated where rtk does the most work. Averaged over 18 tasks it's +4–5% (inconclusive), but on the four Bash-heavy tasks identified in v0.2 it was +38% for v1.1.0 on Haiku (CI +9% to +81%) and +36% for v1.2.0 on Sonnet (CI +5% to +114%).
  • headroom had no measurable effect against a pass-through proxy (Haiku −6%, Sonnet −2%). It compressed requests in every run but removed only about 2% of input tokens.
  • Claude Code updated itself mid-run (2.1.252 → 2.1.322) after 447 of the 810 Haiku runs; all Sonnet runs used 2.1.322. 2.1.322 no longer makes the background title call that skewed caveman's pilot result. See FINDINGS for the version-split analysis.

Limitations

  • Synthetic small-to-medium tasks; both models solved nearly all of them, so the comparison rests on cost.
  • Claude Code changed version during the Haiku run; arms were affected roughly equally (36–45 of each arm's 90 runs on 2.1.322).
  • Default tool configurations and pinned versions; one agent (Claude Code).
  • Costs are API-equivalent: runs used a Claude Code subscription, priced at verified list prices (price table).

Method and reproduction

  • CIs: task-then-run hierarchical bootstrap, 10,000 resamples, paired by task.
  • Reproduce v0.3 (after uv sync && uv run tokentrial install-arms):
    Haiku: uv run tokentrial run --model claude-haiku-5-5 --repeats 5 --seed 3 --out runs/v0.3-haiku --arm baseline --arm noop --arm noop-hook --arm headroom-passthrough --arm rtk --arm rtk-v1.2.0 --arm caveman --arm caveman-v4.1.0 --arm headroom
    Sonnet: uv run tokentrial run --model claude-sonnet-5-5 --repeats 3 --seed 3 --out runs/v0.3-sonnet --arm baseline --arm noop --arm noop-hook --arm headroom-passthrough --arm rtk-v1.2.0 --arm caveman-v4.1.0 --arm headroom
    then uv run tokentrial report --runs runs/v0.3-haiku (and the same for runs/v0.3-sonnet).
